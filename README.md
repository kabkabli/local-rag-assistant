\# Local RAG Assistant

Use command: python chat.py

\## Goal

Build a local AI assistant using:

\- Ollama

\- LangChain

\- ChromaDB

\- Python



\## Models

\- phi3

\- nomic-embed-text



\## Features

\- Read PDF files

\- Store embeddings

\- Answer questions

\- Show document source

\- Show page number

\- Show similarity score
